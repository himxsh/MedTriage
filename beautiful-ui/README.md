# beautiful-ui

Components from [beautifului.dev](https://www.beautifului.dev/).

Each folder has the component source as published on the site (`Copy code` / `View code`).

> Note: As of extraction, the site exposes **Copy code** and **View code** only — there is no separate **Copy prompt** button, so `prompt.md` files were not created.
