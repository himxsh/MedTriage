# Pilot success criteria — one-pager

Agree in writing with the design-partner hospital before live PHI.

## Included

- Deployment + config (IST, roles, templates)
- Clinician onboarding (~1h nurse + 30m physician)
- Evaluation window: **2 weeks** (or 4 if IT delay)
- Weekly 30-min feedback with charge nurse
- Metrics export (Admin → Metrics → CSV)

## Pre-agreed measures

1. Median time intake accepted → structured summary ready  
2. % cases processed successfully (vs Failed)  
3. Confirm vs Override rates  
4. Down-triage rationale completion (≥10 char reason when lowering urgency)  
5. Clinician usefulness (1–5) mid + end of pilot  
6. Uptime during agreed ward hours  

## Rules

- Supervised; non-critical pathway first if hospital requires  
- No marketing “accuracy %” without a review design and advisor OK  
- Real PHI only after security foundation + India hosting + signed DPA
